SmartRent

A rental payment and arrears tracking system for landlords, caretakers and tenants. It records rent payments, calculates balances and arrears automatically, flags defaulters, and lets tenants view their own payment history and receipts.

Unit: Internet Programming (BIT221), Africa International University
Student: Mitchel Mike Kioko (251193BSIT)

Features
Login with hashed passwords and role-based access (Landlord, Caretaker, Tenant)
Manage units and tenants; assign and end tenancies
Record payments (cash, M-Pesa, bank) with printable receipts
Automatic balances and arrears, overdue flags and a defaulters page
Monthly collection report
Tenant portal showing only the tenant's own data
Responsive layout
Technologies

HTML, CSS, JavaScript, PHP (PDO), MySQL, XAMPP
